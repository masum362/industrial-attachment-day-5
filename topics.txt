একটি সাধারণ HTTP কমিউনিকেশনে প্রধান ৪টি অংশ থাকে:
URL / Endpoint: সার্ভারের যে নির্দিষ্ট পাথে রিকোয়েস্ট পাঠানো হয় (যেমন: [https://api.example.com/users](https://api.example.com/users))।
HTTP Method (Verbs): কী ধরণের অপারেশন চালানো হচ্ছে।
Headers: মেটাডেটা (যেমন কনটেন্টের ধরন কী, অথেনটিকেশন টোকেন ইত্যাদি)।
Body: রিকোয়েস্ট বা রেসপন্সে পাঠানো আসল ডেটা (সাধারণত JSON ফরম্যাটে)।

HTTP Status Codes
2xx (Success):
200 OK
201 Created

3xx (Redirection): 301 / 302

4xx (Client Errors):
400 Bad Request: ক্লায়েন্ট ভুল ফরম্যাটে রিকোয়েস্ট পাঠিয়েছে।
401 Unauthorized:
403 Forbidden: পারমিশন নেই।
404 Not Found:

5xx (Server Errors):
500 Internal Server Error: ব্যাকএন্ড সার্ভারের কোডে ক্র্যাশ বা এরর।
502 / 503 Bad Gateway / Service Unavailable

// সাধারণ সিনট্যাক্স (Promise)
const button = document.querySelector("#load-chart-btn");

button.addEventListener("click", () => {
  // বাটনে ক্লিক করার আগ পর্যন্ত এই ফাইলটি ডাউনলোডই হবে না
  import("./heavyChartLibrary.js")
    .then((chartModule) => {
      chartModule.renderChart();
    })
    .catch((err) => {
      console.error("Module loading problem:", err);
    });
});
